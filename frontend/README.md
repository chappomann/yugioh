# Yugioh Card Collection - Frontend

This is the frontend for the Yugioh Card Collection Manager, built with React and Material-UI (MUI) and Vite.

## Features
- Browse all Yugioh cards
- Search, filter, and sort cards
- Manage your personal collection
- Responsive design for desktop and mobile

## Getting Started

### Install dependencies
```bash
npm install
```

### Development server
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

### Environment
- Configuration is handled via Vite and `.env` files if needed.

## Project Structure
- `src/` - React components and logic
- `public/` - Static assets

## API
- The frontend communicates with the backend API (see backend README for details).
