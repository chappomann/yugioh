# Yugioh Card Collection Viewer

A web application for viewing and managing Yugioh card collections built with Node.js, React, and Material-UI.

## Features
- Card collection management
- Card search and filtering
- Card artwork display
- Responsive Material-UI interface

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Environment Variables
See `.env` file for configuration options.
